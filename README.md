# AttendSync

## Smart College Attendance Management System

AttendSync is a web-based college attendance management system designed to make attendance tracking simple, smart, and accessible for both students and faculty.

### Features

- Student Login & Registration
- Faculty Login & Registration
- Faculty Attendance Management
- Student Attendance Dashboard
- Subject-wise Attendance
- Attendance Reports
- Present / Absent Tracking
- Faculty and Student Role-based Dashboard
- Attendance data connection between Faculty and Student dashboards
